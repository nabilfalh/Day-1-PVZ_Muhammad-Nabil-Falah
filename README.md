1. Deskripsi singkat mengenai repository
Secara umum, repository (atau sering disingkat repo) adalah tempat penyimpanan digital terpusat untuk menaruh, mengelola, serta mengatur berbagai berkas, data, atau kode sumber agar mudah diakses, dicari, dan digunakan kembali

2. Tujuan atau kegunaan repository
tempat penyimpanan digital terpusat untuk mengelola, mengatur, dan mengamankan berbagai jenis file, data, atau kode

3. Rangkuman Materi
Workshop ini membahas dua hal: membuat sesuatu dengan AI (prompt engineering) dan mengelola perubahan dengan Git/GitHub. Prompt yang baik memakai struktur Role, Task, Context, dan Format. Git adalah version control lokal, sedangkan GitHub adalah platform online untuk menyimpan repository dan berkolaborasi. Alur Git: working directory → staging area (git add) → repository (git commit) → GitHub (git push). Setup mencakup instal Git dan VS Code, atur identitas, dan buat SSH key. Proyek praktiknya adalah Student Task Planner.

4. Poin Penting
-Konteks dan struktur prompt menentukan kualitas hasil AI.
-Hasil AI perlu diverifikasi sebelum dianggap benar.
-Git (alat lokal) berbeda dari GitHub (layanan online).
-Perubahan melewati tiga area: working directory, staging, repository.
-SSH key membuat koneksi ke GitHub lebih aman dan praktis.
